# Data & attribution

The AGPL-3.0 code license covers the hub's code. The hub itself uses no
outside data: its icons are drawn for it, and it loads nothing from other
sites.

## The name

*Urania's Mirror* is the name of a set of 32 constellation cards published
in London in 1824. The hub only borrows the name; it uses no image from the
cards.

## The games
